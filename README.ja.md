# rain-journal

[English](README.md) | 日本語

ネガティブな気持ちを雨として記録し、雨上がりにやわらかく読み返して改善につなげるエージェントスキル

スキルはユーザーが書いた言語で応答する

## インストール

skills を使う場合:

```sh
npx skills add https://github.com/sayuprc/rain-journal
```

APM を使う場合:

```sh
apm install https://github.com/sayuprc/rain-journal
```

手動で入れる場合: `skills/rain-journal` をエージェントのスキル用ディレクトリにコピーする

`disable-model-invocation` に対応していないエージェントでは、スキルが自動で呼ばれる可能性がある

## 使い方

- 雨を記録する: `rain-journal` を呼び、気持ちをそのまま書く (例: 「今日の会議で何も言えなかった、自分はいつもこうだ」)
- 雨上がりに読み返す: 振り返りたいと伝える (例: 「最近の振り返りをしたい」)

一度呼ぶと雨宿りモードに入り、呼び直さずに話し続けられる

「終わり」「解除」などと伝えるか、セッションを終えるとモードが解除される

## 用語

- **雨**: 吐き出したネガティブな思考や感情
- **晴れ間**: 雨が減った・弱まった兆し
- **傘**: 雨に備える軽いアドバイス

## 記録

記録は `~/.rain-journal/` に Markdown で保存される

- `<日時>.md`: 雨宿りモード 1 回分の雨の記録
- 選んだ傘は、それが応えた雨の記録ファイルの `umbrellas` に残る
